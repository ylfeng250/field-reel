# 数据快照与复盘

公开 API 可拿到投稿时间、播放、赞、收藏、评论、弹幕和分享；拿不到曝光、点击率、完播率、留存曲线、涨粉来源。

## 抓公开数据

```bash
STUDIO=skills/field-reel
python3 "$STUDIO/scripts/account_snapshot.py"
python3 "$STUDIO/scripts/account_report.py"
```

快照进入 `studio/analytics/snapshots/`，报告写到 `studio/analytics/账号复盘.md`。

不要只看总播放。报告按视频发布时间计算年龄，并对 7–180 天的稿件做判断：

- `播放 ÷ 同窗口播放中位数 ≥ 2`：自己的异常高表现，优先找可复用主题；
- `1.5–2`：候选；
- `<1.5`：普通表现。

新片未满 7 天不判成败。不同年代、不同账号、不同平台不直接比绝对播放。

## 创作中心数据

把手工数据填进 `studio/analytics/creator-metrics.csv`：

```text
bvid,recorded_at,impressions,click_rate,avg_watch_seconds,completion_rate,followers_gained,notes
```

百分比写小数，例如 8.4% 写 `0.084`。不知道就留空，不猜。

## 诊断顺序

1. **曝光少**：题材、分区、发布时间或账号受众不匹配。
2. **曝光有、点击低**：先改标题和封面，不急着怀疑内容。
3. **点击正常、前 30 秒掉得快**：开头没及时交代路线和看点。
4. **中段掉得快**：重复走路、相同车窗、旁白碎或信息密度低。
5. **完播可以、互动低**：片子看完没有明确结论或可讨论的问题。
6. **收藏高于点赞**：攻略价值强，适合做同类路线系列。
7. **分享高**：画面、情绪或信息有传播性，标题应更直白。

## 复盘节奏

- 发布当天：只修技术错误，不因播放波动改标题或封面。
- 第 1 天：看评论和公开互动。
- 第 3 天：补创作中心的点击、退出和流量来源。
- 第 7 天：判断开头和包装。
- 第 28 天：判断搜索长尾、收藏和是否进入系列。
- 每四条同类视频只改变一个主要变量；每八条决定继续、改结构或暂停。

实验一次只改一个主要变量：题材、开头、封面、标题或时长。否则无法判断哪项有效。把假设和结果写入 `studio/experiments.md`。
