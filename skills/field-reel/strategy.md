# 账号定位与选题

## 定位

账号不是旅游攻略大全，也不是纯摄影作品集。核心承诺是：

> 一个普通人真的走过、骑过、吃过之后，把路线、现场判断和当时看到的风景留给以后。

用户看完至少得到一种价值：

- **能照着走**：起终点、路线、用时、岔路、补给、季节和坑。
- **像一起去过**：真实口播、现场声、天气、偶发的小事。

不编没去过的体验，不把网上资料说成亲身经历。价格、营业时间、交通班次标明「本人某月出行时」，投稿前再核实。

## 两条栏目

### 边走边说

适合徒步、爬山、骑行、游玩路线、探店。优先级：

1. 现场判断；
2. 路线信息；
3. 风景；
4. 设备和技巧。

### 风景旁白

适合自驾公路、山野湖泊、城市夜景。优先级：

1. 画面变化；
2. 一条连贯的路；
3. 简短可靠的介绍；
4. 音乐和现场声。

## 选题评分

每项 0–5 分，满分 30。总分至少 20 才进入拍摄计划。

| 维度 | 问题 |
|---|---|
| 账号契合 | 属于两条栏目之一吗？ |
| 观众价值 | 能照着走，或值得陪你看完吗？ |
| 独特性 | 有你的现场判断、季节、路线或经历吗？ |
| 画面把握 | 能拍到入口、过程、变化和到达吗？ |
| 可验证 | 地名、价格、里程等信息有可靠来源吗？ |
| 制作成本 | 一次出行能完成，不靠大量补拍或版权素材吗？ |

在 `studio/topic-backlog.json` 记录。状态：

`idea → researched → planned → shot → editing → published → reviewed`

## 选题来源

按优先级找：

1. 自己旧片中播放达到同期中位数 2 倍的主题；
2. 评论或弹幕反复问的问题；
3. 已有但没剪的素材；
4. 同类账号在 7–180 天内达到自身中位数 3 倍的主题；
5. 季节、天气、花期、日落、红叶等时效窗口。

异常高播放说明「题材或包装值得复用」，不等于照抄。只复用结构和观众问题，标题、脚本和实拍必须是自己的。

## 发布节奏

默认以可持续为先：

- 每两周至少一条主片；
- 同一路线只发一条主片，除非第二条解决完全不同的问题；
- 同一题材连续两条表现低于同期中位数，再换包装或暂停，不靠堆量硬发。
