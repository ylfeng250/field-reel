# 成片验收、版权和投稿

## 正式验收

```bash
STUDIO=skills/field-reel
python3 "$STUDIO/scripts/qc_video.py" "<成片.mp4>" \
  --srt "<同名.srt>" --cover "<封面.jpg>" --decision "<素材目录/edit-decision.json>"
```

输出：

- `qc-report.json`：机器可读；
- `质检报告.md`：阻断项、警告和人工复核清单；
- `qc-frames/`：开头、结尾和等距抽帧。

阻断项：

- 文件不能完整解码；
- 没有视频流或音频流；
- 音画时长差超过 0.5 秒；
- 画面尺寸不是偶数；
- 音频不是 48 kHz；
- 综合响度偏离 -14 LUFS 超过 2 LU，或真峰值高于 -1 dBTP；
- SRT 时间越界、重叠，或对应文本不是成片里烧入的版本；
- 封面不符合 B 站建议尺寸 1146×716。

警告项：

- 非结尾出现长黑场、长定格或静音；
- 字幕超过两行、单行超过 16 个全角字符、阅读速度超过每秒 9 字；
- 有意黑场、照片停留也会触发检测，必须看对应抽帧再判断。

## 人工复核

- 字幕没挡脸、路牌、菜单和路线图；
- 地名、日期、公里、海拔、价格和营业时间有依据；
- 画面里没有需要遮挡的脸、车牌、门牌、二维码或私人屏幕；
- 地图没有错误国界、错误地名或错误起终点；
- 音乐在授权范围内，署名原文已经进入投稿简介；
- 手机扬声器和耳机各听一次，口播清楚、风声不刺、音乐不抢。

## 封面和标题

- B 站官方投稿贴士推荐封面 1146×716；最终只交这个尺寸。
- 封面只用真实片中画面，和标题指向同一件事。
- 手机缩小到约 300 像素宽看一次：路线名仍然能读，主体仍然清楚。
- 标题保留统一格式：`YYYY.M.D | 路线，一句话`。
- 一句话必须是片里真实发生的结论，不做无关悬念。

## 标签

B 站官方建议约 4–5 个。顺序：

1. 地点；
2. 活动类型（徒步、骑行、自驾、探店）；
3. 路线或景区；
4. 季节或主题；
5. 系列名（需要时）。

## 投稿包

素材目录至少有：

- 正式 MP4；
- `封面.jpg`（1146×716）；
- 同名 SRT（仅校对留档，画面已烧字幕时不要再上传 CC）；
- `投稿.md`；
- `publish.json`；
- `质检报告.md`；
- 原始素材和 `edit-decision.json`。

投稿后在 `project.json` 记录 `bvid` 和发布时间，把状态改成 `published`。发布动作本身必须由用户确认。
