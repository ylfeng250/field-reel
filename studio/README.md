# 工作室数据

这里保存一个账号自己的资产，不放某一期的大文件。`CHANNEL.md`、`local.json`、素材库、播放快照和实验记录只留在本地。

- `CHANNEL.md`：账号定位和固定风格；
- `topic-backlog.json`：选题池；
- `experiments.md`：制作与运营实验；
- `analytics/`：公开数据快照、创作中心手工数据和复盘；
- `library/`：自有素材索引和联系表；
- `rights/music.json`：配乐来源与授权；
- 各期原始视频仍放在自己的素材目录，里面用 `project.json` 记录状态。

总工作流在 `skills/field-reel/`。视频只走两条分支：

1. `skills/bilibili-walk-talk/`
2. `skills/bilibili-scenic/`
